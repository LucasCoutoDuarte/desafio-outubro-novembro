# Viva Bem – Página de Prevenção e Exames de Rotina

Projeto front-end desenvolvido para a campanha **Viva Bem**, com foco em **prevenção**, **exames de rotina** e **autocuidado** para homens e mulheres.  
A ideia é praticar **HTML + SCSS**, responsividade e uso de **Flexbox** para montar um layout moderno e agradável, inspirado no Figma da atividade.

---

## 🎯 Objetivo da Página

A página apresenta:

- Um **banner principal (hero)** com chamada para ação;
- Uma seção sobre **“A Importância dos Exames de Rotina”**;
- Seções de **Prevenção Feminina** e **Prevenção Masculina**, separadas por faixa etária;
- Uma área de **“Alertas Importantes”** com cards informativos;
- Um **rodapé** com frase da campanha, links úteis e informações de contato/apoio.

Tudo foi construído para transmitir:
- sensação de **cuidado e confiança**;
- **clareza na leitura**;
- e fácil navegação em desktops, tablets e celulares.

---

## 🧰 Tecnologias Utilizadas

- **HTML5**  
- **SCSS (Sass)** – com:
  - variáveis de cores e tipografia;
  - aninhamento;
  - responsividade com media queries;
- **Flexbox** para toda organização de layout (linhas, colunas, centralização etc.).
