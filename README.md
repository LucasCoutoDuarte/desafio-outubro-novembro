# Projeto de Outubro-Novembro (Vai na Web)

# 🌿 Viva Bem – Página de Saúde Preventiva  

# Uma página moderna, responsiva e focada em bem-estar, construída com HTML + SCSS + Flexbox

Bem-vindo ao repositório **Viva Bem**, um projeto desenvolvido para demonstrar **boas práticas de front-end**, organização visual e habilidades com **HTML clássico + SCSS moderno**.  

Este repositório foi pensado para ser **didático**, **profissional** e ao mesmo tempo **agradável aos olhos de recrutadores**, mostrando domínio de:

- construção de interfaces sem uso de frameworks,
- responsividade real,
- design consistente e centrado no usuário,
- código limpo e escalável,
- uso consciente de imagens e semântica.

---

# 🎯 Objetivo do Projeto

Criar uma página completa e responsiva sobre **prevenção de doenças e exames de rotina**, organizada em seções claras e altamente visuais.

O projeto demonstra:

- **Domínio de estruturação de layout**  
- **Uso avançado de SCSS** (variáveis, aninhamento, responsividade, organização)  
- **Aplicação coerente de Flexbox**  
- **Design centrado na acessibilidade**  
- **Integração com imagens reais**  
- **Hierarquia visual profissional**  

Essa página poderia facilmente ser utilizada como:

- landing page institucional,
- página de campanha de saúde,
- projeto de portfólio focado em front-end,
- estudo para aprimorar HTML + SCSS sem frameworks.

---

# 🧩 Funcionalidades & Seções

A página foi dividida em blocos bem definidos para facilitar a navegação:

### ⭐ **1. Hero (Banner Principal)**  
Com chamada motivacional, botões de ação e imagem de destaque.

### ⭐ **2. A Importância dos Exames de Rotina**  
Seção informativa com três cards explicativos.

### ⭐ **3. Prevenção Feminina**  
Cards com imagens reais, divididos por faixa etária, explicando principais exames recomendados.

### ⭐ **4. Prevenção Masculina**  
Mesma estrutura da seção feminina, porém com foco nos exames masculinos.

### ⭐ **5. Alertas Importantes**  
Quatro cards coloridos sobre:
- autoexame das mamas,  
- autoexame dos testículos,  
- vacinas em dia,  
- saúde mental.

### ⭐ **6. Rodapé profissional**  
Com informações essenciais, links úteis e frase da campanha.

---

# 🧰 Tecnologias Utilizadas

**Front-end puro**, ideal para demonstrar habilidade estrutural antes de adicionar frameworks:

- **HTML5 semântico**
- **SCSS modularizado**
  - variáveis de cor, tipografia, tamanhos e sombras
  - aninhamento (nesting)
  - media queries bem distribuídas
- **Flexbox** em todo o layout (sem grid)
- **Arquitetura limpa e escalável**

Esse projeto deixa claro que o desenvolvedor consegue criar interfaces profissionais **sem depender de bibliotecas**, o que costuma agradar recrutadores que buscam versatilidade.
